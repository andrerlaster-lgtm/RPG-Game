=======================================
ROGUE ASSASSIN SHADOW
Free 3D Character for Indie Games
=======================================

Character: Shadow the Rogue Assassin
Style: Low-poly, cartoon
Polycount: ~5,000 triangles
Textures: PBR (diffuse, normal, metallic, roughness)

=======================================
ANIMATIONS INCLUDED
=======================================

1. Idle
2. Walk
3. Run
4. Sneak
5. Attack
6. Block
7. Death

All animations are in-place (no root motion).

=======================================
FORMATS
=======================================

- .fbx (Autodesk)
- .glb (glTF 2.0)
- .obj (Wavefront)

=======================================
GAME ENGINES
=======================================

✅ Unity — import .fbx, assign materials
✅ Unreal Engine — import .fbx, create material instance
✅ Godot — import .glb or .fbx
